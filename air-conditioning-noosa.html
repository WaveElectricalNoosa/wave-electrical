Noosa summers are long and humid, and a well-placed split system makes a real difference to how a home feels — especially bedrooms and home offices. Common Questions

Split System FAQ — Noosa

Can you install a split system I've already bought?
Yes. We can supply the unit for you, or install one you've already purchased. Let us know the make and model when you get in touch so we can check what's needed.
What does a split system service and clean include?
We clean the indoor unit's cover and filters, clean the outdoor coil and clear the condensate drain.
Do you install ducted air conditioning?
No — we specialise in split systems only, including single and multi-head systems.
Does a new split system need its own circuit?
It depends on the size of the system and your switchboard. We check this before quoting, and if a dedicated circuit or a switchboard upgrade is needed, we'll include it in the quote.
Which areas do you cover?
We're based in Sunrise Beach and work across Noosa and the northern Sunshine Coast, including Sunshine Beach, Noosa Heads, Noosaville, Tewantin, Peregian Beach, Cooroy and the hinterland.
